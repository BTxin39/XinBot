# XinBot Web + Desktop Pet 技术决策书

> 版本: v0.1.1 | 日期: 2026-09-21 | 状态: 待实施
>

## 1.决策方向

### 1.1 RAG 向量库标签管理

- 知识库内存储按照tag划分
- 知识库A tag为SM， 角色内含有知识库A的tag SM，则角色可读取改知识库
- 不同角色可进行tag进行查询存储

### 1.2 角色卡 STORY 导入 | 加入角色tag 知识库管理

- 新增故事解析模块，可对玩家导入一个故事，一本小说进行解析，按照该小说导入角色卡
- 预设全部导入（不保证可以识别出来）
- 辅助导入，加入prompt，可明确告诉角色名字，外号，特征，事件，然后AI将这些特征与对应故事情节进行对应加入角色卡

### 1.3 优化角色卡

- 将角色卡进行细分，对应

  ```example
    角色图片（左侧展示，live2D和精灵图可进行切换展示）
    姓名：
    外号：
    性格简介：
    简要经历：
    知识库TAG(点击tag可跳转到向量库管理)
  ```

### 1.4 新增 RAG 向量库可视化管理，增删查改

- 增加矢量图，制作优化可视化关系图

### 1.5 web端加入可视化终端，可进行交互以及查看当前 xinbot 运行状态（如后端，debug调试）

### 1.6 优化web前端布局

- 参考AIRI项目布局以及风格，将左侧索引栏删除，其功能放于右上方，使用折叠形式，增添账号功能（目前仅只有只添加离线账号（里面包含邮箱，用户名，头像，个人简介等等信息）），点开账号的图表会展开档案，设置按钮以及可视化终端按钮，项目属性，预留制作主题更换按钮。
- 再账号左边做一个折叠（标题我没想到叫啥）专门收录管理角色卡，角色记忆，知识库的等等功能
- 然后再左边做一个工具箱（主要是和桌宠主要功能无太大关联的工具箱），依旧采用折叠设计。打开工具箱可展开图片转ascii，新增一个计算器
- 这些折叠里面的按钮打开之后采取那种公告的悬浮弹窗展示，可以进行拖动
- 当前主题采用浅色色调
- 左侧大半边为角色live2D展示区域，用户可以使用左键对角色进行简单交互，中键拖动放大，工具栏，无需展示角色的简单介绍，角色卡更换放在左下角，右侧为聊天区（左下角更换模型，展开可选择是否开启深度思考以及思考强度，右边增加发送文件（图片，pdf那些等等），enter发送，shift+enter换行
